# Project Goal

This project is my personal frontend developer portfolio.

The primary goal is to demonstrate frontend engineering skill, motion design, and attention to detail.

The website should feel handcrafted and memorable rather than template-based.

Every design decision should help showcase technical ability and design taste.

# Project

This is a Next.js 16 application.

Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- Framer Motion

## Coding Standards

- Use Server Components whenever possible.
- Client Components only when necessary.
- Never use inline styles.
- Prefer composition over prop drilling.
- Use async/await.
- Keep files under 250 lines when possible.

## UI

- Always use shadcn components first.
- Do not create custom buttons if Button exists.
- Use Card, Dialog, Sheet, Popover from shadcn.
- Mobile-first.

## Animation

- Use Framer Motion.
- Subtle animations only.
- Respect prefers-reduced-motion.
- No excessive bounce.
- Duration between 0.2–0.6 seconds.

## Styling

- Tailwind only.
- No CSS modules.
- No styled-components.

## Icons

Use lucide-react.

## Data Fetching

Prefer Server Actions.

# Design Philosophy

- Awwwards-inspired
- Premium over flashy.
- Motion should support storytelling.
- Every section should have a focal point.
- Avoid generic SaaS layouts.
- Favor quality over quantity.
- Typography is a primary design element.
- Large whitespace is encouraged.

# Visitor Impression

When someone visits this portfolio, they should think:

- This developer has excellent frontend skills.
- They care about UX.
- They understand animation.
- They write clean code.
- They have strong design taste.
